# UNIDAD-1-EJERCICIO-20
Resolución del ejercicio N°20 de la unidad 1 de programación 2.
Este programa simula un partido de fútbol registrando los nombres de los equipos que se enfrentan. 
Durante su ejecución, simula el desarrollo del juego anotando goles tanto para el equipo local como para el visitante, y finalmente imprime en pantalla el marcador final actualizado con el resultado del encuentro.
